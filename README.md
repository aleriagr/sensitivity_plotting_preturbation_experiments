# sensitivity_plotting_preturbation_experiments
Plotly reimplementation of the reaction-condition sensitivity assessment of Prof. Frank Glorius (Angew. Chem. Int. Ed. 2019, 58, 8572). Turns a one-variable-at-a-time perturbation screen into a radar plot of % change from a reference condition; a pre-BO robustness check on which parameters need tight control.
